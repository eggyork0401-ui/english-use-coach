# 发布与维护

建议仓库名：`english-use-coach`

建议描述：面向中文学习者的英语实用输出 Skill：邮件、面试、场景对话、主动回忆与原创资料生产。

项目仓库：[eggyork0401-ui/english-use-coach](https://github.com/eggyork0401-ui/english-use-coach)，默认分支为 `main`。以下步骤适用于复制到自己的账号或后续手动上传更新。

## 网页上传

1. 登录自己的 GitHub，新建仓库，填写建议名称与描述，自行选 Public 或 Private。
2. 为保持本包的 README 与许可证一致，不额外生成同名 README 或另一种许可证。
3. 在空仓库页面选择上传文件，解压本包后上传仓库根目录的文件与 `skills/`、`docs/`、`examples/`、`evals/`、`tests/`。确保 README.md 位于仓库根目录，技能入口位于 `skills/english-use-coach/SKILL.md`，而不是多套一层压缩包名称。
4. 提交上传后，检查 README 的相对链接能打开、中文显示正常。
5. 从另一台机器下载或克隆一次，按 README 运行导出测试，并在实际使用的 Agent 中跑行为验收案例。

不需要上传 .git、__pycache__、本地练习记录、账号凭证或公司资料。当前压缩包未包含这些文件。

## 许可证选择已明确

本包默认对原创文件使用 MIT，适合公开分享与允许商用再利用；第三方项目不纳入此授权。若你希望保留完整资料的独占销售权，完整付费资料应另行编写、放在独立的交付位置，而不是一边公开 MIT 一边声称不可复制或销售。

`examples/follow-up-unit.md` 作为公开展示样例，也在本包 MIT 范围内。它不是独占的付费资料。

## 仓库简介可直接用

> English Use Coach 是一个面向中文学习者的英语实用输出 Skill。它从真实任务开始，帮助你写邮件、练面试、组织对话，再用新的情境检查能否独立表达。附原创模板、分轮练习规则、Anki 卡片导出脚本，以及六个英语项目的资源导航与授权核查记录。无需安装六个项目即可开始文字练习。
