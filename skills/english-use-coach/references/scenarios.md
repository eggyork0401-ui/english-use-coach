# 场景模板：完成沟通任务

以下英文示例独立编写。`[方括号]` 是按实际情况替换的字段。用户信息完整时直接填入；不要留无用占位符。索引：请求、跟进、延期、拒绝、会议、面试、日常、表达判断。

## 请求与确认

结构：背景（必要时）→ 动作 → 日期/时区 → 用途或备选。

```text
Subject: Request for [document] by [date]

Hi [name],

Could you send me [document] by [date and time zone]? I need it to [purpose].
If that timing is difficult, please let me know when it would be available.

Thanks,
[your name]
```

确认需求：

```text
Just to confirm, you need [deliverable] for [audience] by [deadline].
Should it include [item A], or only [item B]?
```

只写 “Please advise.” 未必语法有错，但具体问题通常更容易得到可执行回复。

## 跟进进度

| 情况 | 表达 | 语气说明 |
| --- | --- | --- |
| 首次跟进，无明确逾期 | I'm following up on [item]. Could you share an update when you have a chance? | 较柔和；有硬性期限就补具体时间 |
| 临近截止 | Could you confirm by [time and time zone] whether [item] is on track for [date]? | 要求确认，不假定已延期 |
| 已过约定日期 | We were expecting [item] on [date], but haven't received it yet. Could you send it by [new requested deadline], or let us know what is blocking it? | 先核对原约定；新期限是请求，不是已经达成共识 |

完整示例（人物与日期虚构）：

```text
Subject: Follow-up: draft slides for review

Hi Alex,

I'm following up on the draft slides we discussed. Could you send them by 3 p.m. Singapore time on 28 October 2026? That will give us time to review them before the client meeting.

If that timing is difficult, please let me know when you can share a draft.

Thanks,
Lin
```

## 汇报与延期

进展：完成 → 进行中 → 障碍 → 所需帮助/下一步。

```text
I've completed [finished item]. I'm now working on [current item].
The main blocker is [blocker]. Could you help with [specific action]?
My next step is [next step]. I expect to [result] by [date], provided [dependency].
```

延期：变化 → 实际原因 → 影响 → 新方案 → 确认。

```text
The [deliverable] won't be ready by [original date] because [actual reason].
I expect to have it ready by [estimated date]. To reduce the impact, I can share [partial output] by [date].
Would that work for your schedule?
```

只有确实可以承诺时才把 “I expect to” 改成 “I will”。不编造“供应商延误”等借口。

## 拒绝与协商

```text
I won't be able to [request] by [deadline] with the current scope.
I can either [option A] or [option B]. Which would be more useful?
```

向领导说明优先级冲突：

```text
I can take this on, but it would mean moving [existing task] to [date].
Which should I prioritize?
```

只有确有可协商范围或优先级时才提供选项。

## 会议与异步确认

| 意图 | 表达 | 使用边界 |
| --- | --- | --- |
| 请求重复 | Sorry, could you repeat the last point? | 没听清时不假装听懂 |
| 确认理解 | Do you mean we should [interpretation]? | 理解待确认 |
| 加入讨论 | Could I add one point here? | 等待适合停顿 |
| 不同意见 | I see the benefit of [idea]. My concern is [specific risk]. Could we try [alternative]? | 不伪造认同或担忧 |
| 临时卡壳 | Let me put that another way. | 接更简单的句子 |
| 需要思考 | Let me think for a moment. | 然后回应 |
| 确认任务 | To confirm, [owner] will [action] by [deadline]. Is that correct? | 不能把讨论当决定 |

会后消息列已确认决定、负责人、期限；未确认内容标 “Open question”。

## 英文面试

自我介绍：当前背景 → 相关证据 → 岗位关联。

```text
I'm a [current role / student background] with experience in [relevant area].
In [real project], I was responsible for [your contribution]. [Verified outcome or concrete deliverable].
I'm interested in this role because [specific connection to the job].
```

没有工作经历时用课程、志愿服务或个人项目。没有数字时写可核对交付物，不造百分比。

行为题按情境、任务、本人行动、结果与反思组织。问 “Tell me about a time you solved a problem.” 时，让用户提供真实经历；必须立即示范时标“虚构示例，不可冒充本人经历”。

追问示例：What did you personally do? / How did you decide which option to try? / What would you change next time?

每轮只问一题并等待，不替面试者连续回答整场面试。

## 日常口语

| 意图 | 基础可用 | 加一条信息 |
| --- | --- | --- |
| 改预约 | Could I reschedule my appointment? | Is there anything available on [day]? |
| 表达偏好 | I'd prefer [option]. | It would be easier for me because [reason]. |
| 询问词义 | What does [word] mean here? | Could you give me an example? |
| 确认位置 | Is this the right place for [service]? | I have a booking under [name]. |

先练信息明确，不把每句话都变成长句。

## 表达判断：别把偏好当错误

| 原句 | 判断 | 按意图改写 |
| --- | --- | --- |
| I very like this idea. | 标准英语语序错误 | I really like this idea. |
| Please reply ASAP. | 语法成立，语气直接且时间不明确 | Could you reply by [time]? |
| I think it's good. | 正确；可能缺具体理由 | I think it works well because [reason]. |
| I don't know. | 正确；下一步取决于真实情况 | I don't know yet. I'll check [source] and get back to you by [time]. |
| Kindly do the needful. | 部分职场英语变体中使用；跨团队时动作可能不明确 | Could you [specific action] by [date]? |

不要强制把 “I think” 换成 “I firmly believe”；这会增加立场强度，可能改变原意。
