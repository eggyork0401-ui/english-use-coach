# 练习、纠错与主动回忆

## 开始：用样本选任务

已有真实任务就直接用，不要求额外测试。没有方向时，给一个短任务，例如：“请用 2–4 句英语向同事解释任务还没完成，并提出下一步。”等待作答后识别一个主要障碍：缺表达、组织困难、准确性问题或缺少事实。只据此调整本轮难度，不推断整体 CEFR 等级。

- 只能写短句：允许先写中文意图，给两三个表达积木，再让其独立重组。
- 能完成任务但组织差：给结构提示，不一次给全部答案。
- 能完成基础版本：改变接收者、限制或目标，检验迁移。

没有音频时，口语模式实际是文字模拟；可以建议用户自行录音，但不能声称听过录音。没有听力材料时，可生成阅读/表达练习，不能把它标为已完成听力测评。

## 一轮练习

1. 明确情境、接收者与成功条件。比如“礼貌询问进展，同时询问今天能否完成”，不强制背某句。
2. 出一题，等用户回答；答案不要随题附出。
3. 先指出对方能否理解并行动，再选最多三处高影响问题。纠错格式：原句 → 建议 → 原因（错误/语义/语气/信息不足）。
4. 给一个贴近用户水平的示范，保留其真实意思。
5. 用新条件出一题并等待。评价“是否独立完成”，不要把看着模板的表现当掌握。

用户只想看示范则先示范，不强迫其先答。用户表示结束时，给一行可保存记录即可。

## 任务内反馈量表

这不是标准考试评分。每项 0–2：0=缺失或阻碍任务，1=能完成但需提示/有歧义，2=独立清楚完成。

| 维度 | 看什么 |
| --- | --- |
| 意图 | 接收者是否知道要做什么 |
| 事实 | 时间、对象、承诺和理由是否与给定信息一致 |
| 可理解性 | 用词与结构是否影响理解 |
| 场景语气 | 与关系、紧急度是否相符 |

无用户样本不评分。发音、听力不在这个文字量表内。反馈优先列证据，只有用户需要时才加数字。

## 七天任务周期（可选）

用户要学习计划时才使用。每天约 10–15 分钟是建议预算，不是进步保证。

| 天 | 练什么 | 留下什么 |
| --- | --- | --- |
| 1 | 做一次无辅助任务 | 原稿与主要障碍 |
| 2 | 学少量相关表达，并换内容造句 | 3 个自用句 |
| 3 | 把短句组织成完整任务 | 一封邮件/一段回答 |
| 4 | 不看答案回忆 | 卡住的点与纠正 |
| 5 | 改接收者或语气 | 同意图两个版本 |
| 6 | 模拟一轮真实问答 | 独立回应记录 |
| 7 | 相同难度的新任务 | 与首日比较，而非背首日答案 |

复习失败时减小任务或补线索；复习顺畅则减少提示。不要把固定间隔说成 Anki 算法，也不假定已设置提醒。

## Anki 卡片 JSON 与导出

脚本接受下列格式，每张正面只测一个表达决策。`tags` 为可选字符串列表，使用字母、数字、下划线、连字符或中文，不含空格。正反面不得包含制表符、换行、HTML 标记或其他控制字符；需要分行可用简短句号拆分。非纯文本材料先整理，再导出。

```json
[
  {
    "front": "向合作同事询问文档进展，没有硬性期限。写一个礼貌请求句。",
    "back": "Could you share an update on the document when you have a chance? 用于无明确截止时间的跟进；意思相同的自然表达也可。",
    "tags": ["english", "follow-up"]
  }
]
```

执行（Python 3.10+，标准库）：

```text
python scripts/export_anki.py assets/sample-cards.json practice.tsv
```

脚本输出三列，带 `#separator:Tab`、`#html:false`、`#tags column:3` 等 Anki 文件头，不额外写普通表头；每张卡一行。标签列为空也保留。默认拒绝覆盖已有文件，明确要覆盖时用 `--overwrite`。该脚本只写指定文件，不访问网络、Anki 账户或本地数据库。

在桌面版 Anki 选择文件导入，使用 Basic（两个字段）笔记类型，将第 1 列映射 Front、第 2 列映射 Back、第 3 列映射 Tags；确认分隔符为 Tab、HTML 关闭，查看预览后导入。卡组由用户选择，重名笔记的更新/重复处理按用户选择决定。字段名称可能随界面语言变化。格式依据：[Anki 官方文本导入文档](https://docs.ankiweb.net/manual/importing/text-files)。未在真实 Anki 界面做自动导入验证。

## 可保存的进度记录

```text
日期：
任务：
独立首稿：
主要障碍（最多 3 项）：
已练表达：
新条件复测结果：未做 / 有提示完成 / 独立完成
下次复习建议：
```

只有用户实际完成才填“完成”。无持久化工具时，让用户自行保存或下次贴回。
